Quick setup

Load the extension directly in Chrome. The unpacked folder must contain manifest.json.

1

Download and extract the latest ZIP from the GitHub releases.

2

Open chrome://extensions and turn on Developer mode.

3

Select Load unpacked and choose the extracted extension folder.

4

Open the extension from Chrome’s toolbar and create your first entry.

Local and lightweight

Stored on this browser

Entries, category names, and theme use chrome.storage.local.

Backups are yours

Backups require version 2.0.0 or later. Choose plain JSON or password encryption; forgotten passwords cannot be recovered.

Updating from an older version

Update or reload in place to keep local entries. Uninstalling may remove the extension's stored data.

No cloud or tracking

No analytics, remote scripts, or server-side snippet storage.

Only what it needs

The extension uses local storage and clipboard access for its features.
